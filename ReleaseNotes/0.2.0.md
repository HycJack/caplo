- 新增显示按键：录制时可记录快捷键或全部按键，成片上显示为键帽
  Keystroke display: record shortcuts or all keys and show them as keycaps
- 时间线新增按键轨，不想显示的那一组可以单独删掉
  Keystroke track on the timeline, remove any group you don't want shown
- 新增去除静音，一键剪掉停顿
  Remove silence: cut pauses in one click
- 新增提词器，不会录进画面
  Teleprompter that stays out of the recording
- 新增文字或图片水印
  Text or image watermark
- 区域录制记住上次的范围，可隐藏桌面图标，录制中可开关人像
  Region recording remembers the last area, desktop icons can be hidden, and the camera can be toggled while recording
- 导出完成后可拷贝到剪贴板，默认导出到“影片”里的 Caplo 文件夹
  Copy the export to the clipboard when done, exports go to the Caplo folder in Movies by default
- 导出未完成时关闭窗口或打开其他工程，会先确认
  Asks before closing the window or opening another project while an export is in progress
